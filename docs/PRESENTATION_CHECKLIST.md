# Presentation Checklist

## Day Before

- [ ] `git pull origin main`
- [ ] Activate `.venv`
- [ ] Install dependencies
- [ ] Confirm `.env` exists locally
- [ ] Run `python -m finsent.scripts.demo_preflight`
- [ ] Run `python -m finsent.scripts.demo_preflight --warm`
- [ ] Start dashboard and open `http://127.0.0.1:8050/`
- [ ] Verify data bundle contents if using another machine
- [ ] Confirm browser zoom and display scaling
- [ ] Prepare backup offline explanation using the Research page

## Before Entering Room

- [ ] Internet connected
- [ ] Charger connected
- [ ] `.env` not visible on screen
- [ ] Virtual environment active
- [ ] Dashboard running
- [ ] Correct commit visible in System Status
- [ ] Optional warm-up complete
- [ ] Browser tabs open for Overview, Stock Research, News, Compare, Research
- [ ] Backup symbols ready: `META`, `JPM`, `AMZN`

## After Demo

- [ ] Do not expose or share `.env`
- [ ] Stop server if needed
- [ ] Close terminals showing local paths or credentials
